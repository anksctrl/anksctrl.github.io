# Greatness Marcus — GitHub Pages Portfolio

This package is the recruiter-focused v3 refresh of the portfolio.

## Files
- `index.html` — homepage, profile, selected projects, experience, capabilities and contact
- `style.css` — responsive visual system
- `detail.css` — case-study styling
- `aquaneural.html` — AquaNeural case study
- `metro-link.html` — Metro-Link project autopsy
- `true-vine.html` — True Vine Hospital EMR migration
- `assets/AquaNeural_Project_Portfolio_Greatness_Marcus.pdf` — flagship PDF
