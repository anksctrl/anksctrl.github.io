# Greatness Marcus — Project Management Portfolio

GitHub Pages portfolio package.

## Upload
1. Extract this ZIP.
2. Upload the contents of `Greatness_Marcus_PM_Portfolio_v5/` to the root of your `anksctrl.github.io` repository.
3. Commit/push the files.
4. GitHub → Settings → Pages → Deploy from branch → `main` → `/ (root)`.

## Public artefacts
The `artefacts/` folder contains sanitized AquaNeural summaries. The confidential source Business Case/PMP files are intentionally excluded.
