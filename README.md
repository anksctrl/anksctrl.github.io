# Greatness Marcus — GitHub Pages Portfolio

A professional portfolio site for Greatness Marcus, focused on project management, business analysis, FinTech and Health IT.

## Publish
1. Create a public repository named `<your-github-username>.github.io`.
2. Upload all files from this folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/root`, then Save.
5. GitHub Pages will publish the site at `https://<your-github-username>.github.io/`.

Before publishing, replace `YOUR_EMAIL_HERE` in `index.html` with your professional email.

The AquaNeural portfolio PDF is already included in `assets/`.
